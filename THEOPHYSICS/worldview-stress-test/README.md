## The Argument

The axiom graphs are surprisingly close — especially panpsychism. 
The case is won at the edges: where each framework runs out of answers.

Theophysics terminates in a generative ground (God) that produces 
downstream structure. Competitors terminate in open problems. 
The graph shows the skeleton. The papers show the meat.
