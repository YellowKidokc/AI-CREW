# 01 Sorted Review

This folder is for material that has been inspected once and labeled.

Use subfolders as needed:

```text
axioms/
equations/
lagrangians/
isomorphic-events/
claims/
evidence/
objections/
audit/
paper-sections/
glyphs/
mtl/
```

An item in this folder should answer:

- What kind of object is it?
- What source did it come from?
- What claim or paper section does it support?
- Is it ready, unresolved, overstated, or rejected?
- Should it feed the Knowledge Atom, the big paper, or the archive?

Sorting rule:

Nothing becomes canon from here automatically.
It must earn promotion into `02_CROWN_CANON`.
