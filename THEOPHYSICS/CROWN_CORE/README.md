# Crown Core

This is the drop-and-sort workspace for the Master Equation / Trinity / Crown material.

Use this when material feels important but has not yet earned its final place.

## Folders

```text
00_INBOX_MASTER_EQUATION/
```

Drop raw material here.
Anything can enter this folder: notes, AI outputs, drafts, copied source files, objections, equations, screenshots converted to text, or half-formed ideas.

```text
01_SORTED_REVIEW/
```

Material moves here after first sorting.
Each item should be labeled by what it is: axiom, equation, Lagrangian, isomorphic event, evidence, objection, paper section, glyph, MTL, or audit note.

```text
02_CROWN_CANON/
```

Only material that should feed the read-first Knowledge Atom or the big Crown paper goes here.
This is not casual storage.

## Working Rule

Inbox receives.
Sorted Review classifies.
Crown Canon preserves what earned its place.
