## THE PROOF STANDARD

Every property must be tested as a full structural proof, not a description match. For each of the 24 properties, each AI must answer:

1. **Define it identically across all three domains.** Same predicate, same meaning, not three different meanings wearing the same word. If the meanings diverge, the proof fails for that row.

2. **Show it's required, not optional.** The domain breaks without it. Not "it's nice to have." Not "it's commonly assumed." The domain DIES without it.

3. **Show it works the same way.** The property doesn't just exist in all three — it OPERATES the same way. Same structure, same constraints, same consequences when violated.

4. **Read it forward.** Starting from God's nature, does this property predict what we find in math and physics? Did the prediction come before the observation?

5. **Read it backward.** Starting from what physics requires, does this property lead you back to math and then to God? Is there any other terminus?

6. **Kill it.** Try to break it. Find a counterexample. Find a domain where the property works differently. Find a rival explanation that doesn't need God. If you can't kill it, it lives.
