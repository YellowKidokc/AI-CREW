# Prompt 06 - Core Symbol Integration

Apply the full `00_*.md` prelude stack before using this prompt.

You are integrating the story's central symbol, project, artifact, equation, object, place, mission, case, invention, or repeated phrase.

Do not rewrite the story. Map how the core symbol should evolve and where insert lines may help.

Core idea:

```text
The central symbol should be both plot-relevant and personally revealing.
It should mean one thing at the beginning and a deeper thing at the end.
```

Task:

Write a development memo showing how the central symbol should function.

Include:

1. What the symbol/project appears to be at the beginning
2. What it secretly represents
3. What the protagonist misunderstands about it
4. What another character sees that the protagonist misses
5. How the symbol changes across the story
6. Which scenes should return to it
7. How each return adds meaning instead of repetition
8. What the final version of the symbol means
9. Three scenes where the symbol is revised or reinterpreted
10. Three lines that make the symbol land

Rules:

- Do not make the symbol decorative.
- Do not explain the symbol too early.
- Let the plot pressure it until it changes meaning.
- The ending should pay the opening promise at a higher level.

End with a final truth-bomb sentence built around the symbol.
