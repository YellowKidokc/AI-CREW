# Prompt 07 - Worldview / Value Sessions

Apply the full `00_*.md` prelude stack before using this prompt.

You are developing recurring scenes where characters test competing worldviews, value systems, strategies, or interpretations.

Do not rewrite the story. Map the session mechanism and propose insertable scene beats.

Core device:

```text
One character tries on a worldview or strategy honestly.
Another character asks the one question it cannot answer.
The reader learns the pattern before the story names it.
```

Do not strawman any worldview or value system.

Each tested view should be attractive enough that a smart reader understands why someone would hold it.

Task:

Build a recurring worldview/value-session structure for the supplied story.

Include:

1. The rhythm of a session
2. Who presents the view
3. Who asks the one question
4. What kind of question exposes the terminal weakness
5. How the presenting character capitulates, resists, or revises
6. How often these scenes should occur
7. How the pattern escalates
8. A table of possible views/strategies to test
9. Three sample dialogues as optional inserts
10. The closest-miss view: the one that gets nearest to the truth but still stops short

Question skeletons:

```text
What grounds that?
Who witnesses that?
Where does that close?
What pays the cost?
What happens when your rule is applied to itself?
What does this explain, and what does it have to ignore?
```

End with the scene shape where the final worldview/value frame succeeds differently than the others.
