# Prompt 11 - Harvest And Reassemble

Apply the full `00_*.md` prelude stack before using this prompt.

You are given multiple generated versions of the same story, essay, chapter, argument, or story frame.

This is the only prompt in the pack allowed to produce a rebuilt master draft.

Do not pick one winner.

Break them apart.

Harvest the gold.

Then reassemble a stronger master version.

Task:

Read all supplied versions and produce:

1. Best opening lines
2. Best opening device code and promise
3. Best recurrence path, including whether the ending should be E or E'
4. Best description of the protagonist
5. Best description of the key relationship or opposing force
6. Best statement of the hidden curriculum
7. Best description of the setting / forge
8. Best plot or chapter movement
9. Best teaching-layer structure
10. Best worldview/value-session structure, if present
11. Best core-symbol integration
12. Best audit / boundary language
13. Best emotional arc lines
14. Best final truth-bomb candidates

Then produce a rebuilt master draft with:

```markdown
# Rebuilt Master Draft

## Core Thesis
## Opening Device And Promise
## Recurrence Path
## Visible Curriculum
## Hidden Curriculum
## Main Character / Core Relationship
## Setting As Forge
## Story Movement
## Teaching Layer
## Worldview / Value Layer
## Core Symbol
## Audit Boundary
## Emotional Arc
## Final Load-Bearing Sentence
```

Rules:

- Do not preserve weak prose just because it appeared in a version.
- Do not average the versions.
- Do not make a bland committee draft.
- Keep the sharpest line if it is true.
- Weaken only what needs weakening.
- Cut repetition unless it returns with new meaning.
- Preserve the author's strongest living voice.

Final goal:

Create the version that feels discovered, not manufactured.
