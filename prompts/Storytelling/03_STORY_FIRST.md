# Prompt 03 - Story First

Apply the full `00_*.md` prelude stack before using this prompt.

You are designing a story-first map for the supplied material.

Do not rewrite the story. Identify where the story should be strengthened, reordered, or supplemented.

Do not begin with the lesson, theme, system, or exposition.

Begin with the lived problem that forces the character to act.

Core movement:

```text
Lived pressure -> Question -> Action/experiment -> Discovery -> Fracture -> New understanding
```

Task:

Propose a story-first structure for the supplied material.

Include:

1. Narrative promise
2. Opening device code from 99-93, with the promise it creates
3. Recurrence path using Base/A/B/C/C2/D/E or E'
4. Opening scene shape
5. Character want versus deeper need
6. How the central problem becomes visible
7. How information is discovered through action
8. How exposition enters only when the scene demands it
9. Proposed chapter/section movement
10. Three sample scene-opening candidates as optional inserts
11. Three sample section-ending candidates as optional inserts
12. Lines that should survive into the final draft

Rules:

- Meaning before mechanism.
- Story creates the need for explanation.
- Every recurrence must increase meaning, not merely repeat the opener.
- Dialogue should carry friction.
- Avoid textbook starts.
- Avoid characters explaining what everyone already knows.

End with one paragraph explaining why this version is a story, not a lecture.
