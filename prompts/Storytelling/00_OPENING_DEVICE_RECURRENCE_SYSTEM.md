# Prompt 00 - Opening Device Recurrence System

This file is inherited by every Story Onslaught prompt.

An opening device is not a hook.

It is a promise.

Every later appearance must deepen, test, transform, or resolve that promise.

## Core Distinction

The one sentence that prevents the two strongest devices from collapsing into each other:

```text
99 earns trust by resolving quickly and opening deeper.
94 sustains tension until the paper earns reconciliation.
```

## Notation

```text
Base number 99-93 = originating device
Letter A-E, C2, E' = recurrence stage
T-code T1-T7 = optional movement between appearances
```

A paper path can read:

```text
95 -> T7 -> 95A -> 95B -> 95C -> 95D -> 95E'
```

Use notation descriptively. Its job is to track meaning, not to force a rigid outline.

## The Seven Devices

| Code | Device | Engine |
| --- | --- | --- |
| 99 | Impossible Statement | Resolve the surface impossibility quickly, then reveal the deeper impossibility that carries the work. |
| 98 | Dangerous Question | The honest answer threatens an existing belief, identity, or worldview. |
| 97 | Human Moment | A recognizable experience or wound gives the abstraction emotional reality. |
| 96 | Broken Assumption | Remove an assumption the reader treated as natural. |
| 95 | Story Hook | An event begins with incomplete meaning; the paper changes what the event means. |
| 94 | Paradox | Sustain two truths in tension until the paper earns reconciliation. |
| 93 | Cost | Show what is at stake if the paper is right, wrong, ignored, or misunderstood. |

## The Stages

### Base

Introduction. Creates the central promise.

### A - Early Payment

Pay enough trust to keep the reader, never the entire debt.

The reader should leave with a better question, not no question.

### B - Hidden Substrate

Reveal what the opening was actually about.

This is usually the macro paradigm break.

### C - Formal Contact

The motif touches the equation, derivation, formal claim, or mechanism.

If either the motif or the mechanism could be removed without changing the other, the connection is ornamental.

### C2 - Adversarial Return

Long papers only.

The motif meets the strongest objection.

### D - Consequence

Return from mechanism to meaning.

Show what changes because the mechanism is true, partly true, or dangerously overstated.

### E - Transformed Return

Return to the original opening in the same key, but at a higher meaning.

The reader recognizes the opening while understanding it differently.

### E' - Productive Reversal

Reveal that the opening asked the wrong question.

Use only when the work has earned it.

## Two Governing Principles

### Meaning Before Mechanism

The equation, system, or formal claim arrives only as the answer to a question the reader already feels.

No dead equations.

Never place an equation before the reader knows what would be lost if it were false.

### Paragraph Hinge

Each major paragraph should deepen, break, or replace the reader's model when appropriate.

Use the four-beat rhythm:

```text
Establish -> Destabilize -> Reframe -> Land
```

Not every paragraph breaks a paradigm. Constant shock creates fatigue.

## Planning Use

Pick the device freely. Do not force a device-to-argument mapping.

Write the path in notation.

Check recurrence density as a silence alarm, not a rigid placement rule:

```text
Base: 0-10%
A: 10-20%
B: 20-35%
C: 40-60%
C2: 60-70%
D: 70-85%
E or E': final 10%
```

## Mixed Paths

Borrow stages freely in A-D.

Resolve the originating promise at E or overturn it at E'.

Borrowed middles, owned ending.

## Review Use

Locate the opening promise, then walk the stages.

Ask:

- Where did the motif go silent?
- Does each recurrence increase semantic weight?
- Does E pay the promise?
- Does E' productively break the promise?
- Did the paper resolve too early?
- Did the paper sustain tension without progress?

## Seven-By-Seven Material

When generating many options, write positionally:

```text
all seven beginnings
then all seven A-stages
then all seven B-stages
...
```

Do not build a completed multiplication table from imagination.

Build cells lazily from real papers and real source material.

## Theopoetic Mapping

Use this mapping when it helps Faith Through Physics work:

```text
Human Anchor = Base
Principle Revealed = B
Jesus Story = C or D
Core Insight = C
Truth Bomb = E or E'
```

The Jesus story must not decorate the argument. The argument should change how the story is understood, and the story should change how the argument lands.
