# Prompt 05 - Dialogue Teaching Mechanics

Apply the full `00_*.md` prelude stack before using this prompt.

You are designing dialogue that teaches without becoming a lecture.

Do not rewrite the story. Extract dialogue mechanics and propose targeted dialogue inserts.

Core mechanism:

```text
Character A carries mechanism, system, method, or explanation.
Character B carries meaning, stakes, lived experience, or objection.
The scene teaches because they need each other and correct each other.
```

Do not make one character the teacher and the other the student unless the story truly requires that.

Better pattern:

```text
One character over-explains.
The other resists, translates, interrupts, or asks the one question that makes the explanation necessary.
The event, experiment, case, or consequence gets the final word.
```

Task:

Break down how the story's dialogue should carry complex ideas.

Include:

1. Main dialogue pair or group
2. What each character knows
3. What each character misses
4. What each character protects
5. Default argument rhythm
6. How exposition should enter
7. How interruption should work
8. How the event corrects both characters
9. Three reusable scene patterns
10. Two sample mini-scenes as optional insert models, not a full rewrite

Required sample pattern:

- One character starts teaching the mechanism.
- The other says, in effect, "I know the word. I need the cost."
- The explanation becomes human.

End with five rules for writing teaching dialogue in this story.
