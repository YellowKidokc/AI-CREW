# PROMPTS — Reusable AI Task Prompts

tags: #prompts #codex #automation

**Purpose:** Reusable prompt files for recurring AI workflows. Each prompt is a self-contained task spec that any AI or API can execute.

**Naming:** `PROMPT_{CATEGORY}_{NAME}.md`

**Categories:**
- `DB` — Database / SQLite / query prompts
- `MTL` — Math Translation Layer prompts
- `CLAIMS` — Claims ledger, evidence matching
- `PAPER` — Paper hierarchy, publication pipeline
- `CORPUS` — Corpus-level ontology, structure
- `INTAKE` — File intake, parsing, classification

**Usage:** Copy the prompt, paste to the target AI or API call. Each prompt declares its inputs, outputs, and what database/files it expects.
