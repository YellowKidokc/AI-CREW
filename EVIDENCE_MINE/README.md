# EVIDENCE_MINE
## Argument Repository for the Theophysics Framework

All AI evidence cards go here. One file per AI, named:
`[AI-NAME]_EVIDENCE_CARDS.md`

After collection, David + lead AI merge into per-property files:
`PROPERTY_01_NECESSARY.md` through `PROPERTY_24_JUDGING.md`
plus `UNCATEGORIZED.md` for strong arguments that don't map to the 24.

See `../EVIDENCE_MINING_PROTOCOL.md` for the full prompt and card format.
