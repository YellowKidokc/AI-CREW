## Tools

### Hoffman FBT

Hoffman's Fitness Beats Truth theorem supports the claim that, in modeled
evolutionary games, fitness-only perceptual strategies can dominate truth
strategies, with dominance increasing as perceptual space grows.

Use:

```text
FBT pressures the assumption that perception is selected primarily for truth.
```

Limit:

```text
FBT is primarily about perception/interface strategies. It does not by itself
prove that all cognition, logic, mathematics, or scientific reasoning is
unreliable.
```

### Plantinga EAAN

Plantinga's Evolutionary Argument Against Naturalism argues roughly:

```text
If naturalism and unguided evolution are both true, then the probability that our
cognitive faculties are reliable is low or inscrutable. If one sees that, one
has a defeater for trust in those faculties, and therefore a defeater for every
belief produced by them, including naturalism and evolution.
```

Use:

```text
EAAN pressures question 12: can naturalism coherently trust the reasoning by
which it affirms naturalism?
```

Limit:

```text
EAAN is contested. A naturalist can reply that truth-tracking is fitness-linked,
that cognitive reliability is locally selected, that science is socially
self-correcting, or that externalist reliabilism does not require prior proof of
reliability.
```

## Question 12: The Core Finding

Question 12 asks:

```text
Does the explanation remain coherent when applied to its own reasoning?
```

For the rational source model:

```text
Reason is expected to be truth-aimed because reason is grounded in a rational
source. Error remains possible because finite minds are limited or corrupted,
but error is a defect relative to truth, not the whole explanation of cognition.
```

For adaptive cognition:

```text
Reason is selected for adaptive success. That can include truth-tracking, but it
does not automatically equal truth-tracking. Adaptive usefulness and truth can
diverge.
```

Hoffman sharpens this:

```text
Fitness can beat truth in modeled perceptual evolution.
```

Plantinga sharpens the self-application:

```text
If naturalism plus evolution gives low or inscrutable probability to cognitive
reliability, then the naturalist has a defeater for trusting the faculties that
produce naturalism itself.
```

The formal pressure is:

```text
Naturalism must prove, assume, or externally justify a reliability bridge:

adaptive_success -> truth_tracking_reliability
```

Without that bridge, it does not pass question 12.

## Naturalist Escape Routes

A fair naturalist can respond:

1. Truth is often fitness-enhancing.
2. Science is not raw perception; it uses instruments, mathematics, replication,
   peer correction, and error control.
3. Evolution selects not only beliefs but behavior-producing systems; reliable
   world-modeling can be useful.
4. Externalist reliabilism says faculties can be reliable without internally
   proving their reliability first.
5. EAAN's probability claim is disputed; critics deny that `P(R | N&E)` is low
   or inscrutable.

These replies matter.

Codex #2 ruling:

```text
Naturalism can survive question 12 only by adding a substantial truth-fitness or
science-correction bridge. It cannot simply say "evolution produced cognition"
and then use that cognition as if truth reliability had already been grounded.
```

## Six-Year-Old Version

Imagine your brain is a tool made to keep you alive.

That is good. A survival tool can be very useful.

But now ask: was it made to show you what is true, or only to help you win the
game?

If it was only made to help you win, then when it tells you "this is true," you
have to ask whether it found truth or just found a move that works.

The God-grounded view says reason comes from Reason, so truth is part of what the
tool is for.

The naturalist view can still answer, but it has to show why a survival tool is
also a truth tool.

That is the whole fight.
