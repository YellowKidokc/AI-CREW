# CONTROL 4 - Information -> Computation -> Matter

Codex negative-control ablation suite  
Date: 2026-08-04

## Control Purpose

This triad tests whether a secular information-first ontology can reproduce the seven clusters.

```text
information -> computation -> matter
```

This is a serious rival because it can imitate Logos-like structure without a personal source.

## Scoring Rule

0 = no match  
1 = weak analogy  
2 = bridge analogy  
3 = ambiguous / partial structural match  
4 = strong structural match  
5 = near identity inside the control triad

Criteria considered:

- identical meaning;
- requiredness;
- same consequence on removal;
- bidirectional readability;
- boundary pattern preservation.

## Boundary Pattern Audit

The boundary pattern is technically strong:

```text
information -> computation -> matter -> measured state feedback
```

It breaks at personhood and normativity. It explains processing, not why truth is binding, why consciousness is more than functional state, or why moral authority exists.

## Discrimination Finding

This control threatens the formal/information parts of the proof. It fails mainly at Modal and remains ambiguous at Ontological and Scale.
